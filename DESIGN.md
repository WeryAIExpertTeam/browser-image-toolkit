# WeryAI Image Toolkit design context

## Overview

The approved direction is the wery.ai logo and mascot, near-black/white surfaces, a restrained pink punctuation dot, and rounded Quicksand headings. Source: the owner's 2026-10-19 brand-replacement brief and supplied v3 preview. Preserve that identity rather than the previous purple theme.

This is a hybrid: the compressor home explains the product and performs a local task; tools.html and the extension are task-focused editors. Audience: global desktop creators preparing image files, with a usable narrow layout. The compressor is English; the other-tools page retains its existing English/Chinese switch. There is no Japan-specific workflow, Japanese UI, billing or identity input in this change.

## Colors

Runtime tokens are authoritative: assets/compressor.css owns --ink, --paper, --card, --brand, --on-brand, --dot and their system-dark variants. Home and extension consume those tokens; tools.html uses the existing --text/--bg/--accent adapter in assets/toolkit.css. These are deliberate shell adapters, not separate redesigns. No token generator is used.

Dark mode changes the home/extension primary surface to #030303 and text to #fafafa; the brand mark is inverted to white. Success/error colors remain semantic. Pink is decorative emphasis and focus, not the only indication of outcome. Scrollbars inherit the document's neutral colors and retain system handling in forced colors. The theme follows the browser by default; `html[data-theme="light"|"dark"]` forces one. The extension has an Auto / Light / Dark button (extension/theme.js, remembered in localStorage).

## Typography

Quicksand is self-hosted under OFL 1.1 and used for headings and brand labels. Body controls retain the system stack for readable filenames and numbers. Chinese falls back to platform Chinese fonts rather than forcing Latin letter spacing.

## Layout

The hero's live compressor is the main action. The mascot peeks from behind it; other tools, AI links and extension information follow. Home content max width is 1080 px; the compressor is 860 px. At 640 px the navigation collapses to the brand mark and Try WeryAI, and the hero mascot hides. At 560 px compressor controls wrap rather than overflow.

## Elevation & Depth

Keep panels lightly elevated with the existing --shadow. Comparison uses a native modal dialog in the browser top layer, with a dimmed backdrop. The document scrolls normally outside the modal; the dialog body may scroll when short viewports require it.

## Shapes

Cards use --radius (20 px), smaller control panels use --radius-sm (14 px), and main actions use pill outlines. Preserve the original mascot and logo proportions. Brand assets and extension icons are excluded from MIT; forks replace their branding.

## Components

| Capability | Canonical owner | Contract and verification |
|---|---|---|
| Compression and progress | assets/compressor.js + compress-core.js | Shared on home and extension; original byte-size guard remains; success/error states stay per file |
| Select/Listbox | Existing native select controls | Platform-owned popup and keyboard behavior are accepted; no custom listbox in this scope |
| Compare overlay | Compressor.prototype.compare | Native dialog gives modal focus containment/inert background; close button, Escape and focus restoration; slider offers keyboard alternative to dragging |
| Branding/theme | compressor.css, landing.css, toolkit.css, extension/app.css | Verify home and sibling tool at desktop/narrow widths; dark mark via system color scheme |
| Feedback | Existing file rows and flash status | Do not replace existing failures with fake success; no image upload introduced |
| Scrollbar | Document styles in compressor.css, existing tools shell | Visible neutral scrollbar, stable gutter, forced-colors fallback |

The extension assets are generated by bash scripts/build-extension.sh from shared assets. Edit the shared compressor once, then rebuild; never hand-edit its generated copy.

## Do's and Don'ts

- Keep compression local and preserve the no-larger-file behavior.
- Keep the logo, mascot and pink dot specific to wery.ai; avoid reintroducing purple primary controls.
- Use buttons for actions and links for navigation, visible focus, text outcomes, and reduced-motion overrides.
- Compare only completed conversions; original-kept results do not pretend to offer a new image.
- Keep store publishing paused. No tokens, account data or private workflow configuration belong in this project.
