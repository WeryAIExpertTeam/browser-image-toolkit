Questions

Are my images uploaded to a server?

No. Compression runs inside your browser using the Canvas API and Web Workers. Your files are processed on your device. JPG, PNG and WebP work offline once the page has loaded; the first HEIC import needs a network connection to download decoder code.

Which formats are supported?

JPG, PNG, WebP, HEIC (iPhone photos), GIF (first frame) and BMP. You can keep the original format or convert to JPEG, WebP or PNG under More options.

Can it make my image smaller than a specific size?

Yes. Open More options and set a target size in KB. The compressor lowers quality, then tries smaller dimensions. If it cannot reach your target, the result is marked Target not reached.

Why does a file show “Already optimized”?

If re-encoding would make the file bigger, the compressor keeps your original instead. This also applies to format changes, resizing and HEIC: if the result would grow, the original is returned and any skipped change is explained.

Is it free?

Yes. No limits, no watermarks, no account. The source code is MIT-licensed on GitHub.
